Canonical paths and project context rules
Back to index

Project context rule. Dashboard and global Settings (/settings) are cross-project. Board, Wiki, and project Settings (/:slug/settings) are project-scoped. The global project switcher preserves the route type when possible. If the current route does not exist in the new project (e.g., a wiki page when the target project has no wiki), fall back to that project's board (/:slug).
