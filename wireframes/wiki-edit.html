Elemental Damage

Emberfall’s combat revolves around four elemental affinities: Fire, Ice, Earth, and Wind. Each enemy and boss has a hidden resistance matrix that determines damage multipliers.

Damage Formula

Base damage is calculated from the weapon’s attack_power stat, modified by the player’s current affinity and the target’s resistance.

func calculate_damage(attack_power: int, affinity: String, target: Enemy) -> int:
    var base = attack_power * player.affinity_bonus(affinity)
    var resistance = target.resistance[affinity]
    var multiplier = 1.0 + (1.0 - resistance) * 2.0
    return int(base * multiplier)
