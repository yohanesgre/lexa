Dropdown Menu
Sections, icons, Mono shortcuts, keyboard focus ring, pinned danger action.
components/DropdownMenu.tsx
Forge Control Panel
Global task history across all projects: summary strip (active/queued/done/failed/runtimes), status chips + project/action filters, task table with live rows, paginated history, detail slideover with activity feed + markdown result.
/forge.tsx
Forge Popover
AI writing assistant popover: agent + skill pickers (skills attach to agents), runtime selector, per-run additional prompt, Generate, running state, result review. Accept → review in editor.
components/forge/ForgePopover.tsx
Forge Review in Editor
Result preview inside the editor at full width: whole-document diff, review banner with Accept/Reject, snapshot restore on reject.
components/forge/ReviewBanner.tsx
Runtime Setup Modal
4-step machine-first wizard (Machine → Agent CLI → Key / Send → Verify) opened from Settings → Agent Runtimes. Completed runtimes expose listener-reported agent/model catalogs for Settings.
components/forge/RuntimeSetupModal.tsx
Runtime Edit Modal
Edit config of an existing runtime from the ⋯ row action: daemon-reported identity strip, name, live provider-aware model picker (catalog from the agent, ~10 min refresh; presets fallback when offline), injectable extra CLI args list. Server-authoritative — applies on next task.
components/forge/RuntimeEditModal.tsx
Runtime Restart Modal
Recovery path for an offline runtime: why it's offline, the exact restart command (manual + systemd) with this runtime's agent/model baked in, and live polling that closes when it's back online.
components/forge/RuntimeRestartModal.tsx
404 Page
Full-page not-found with route readout and a dashboard back link.
/404.tsx
