Connect a machine with an agent CLI installed (opencode, hermes, or command-code). Setup generates the exact env + start command.

Table: the machine listener owns daemon children; runtime rows self-register + heartbeat. Agent CLI + hostname + status are telemetry. Model + agent + logging + extra args are server-authoritative config: the gear opens settings-runtime-edit.html and applies on the next Forge task. Remove is explicit and online-only: the server queues a remove event, deletes the row, and the listener kills the matching child + env directory. Setup opens settings-runtime-setup.html. MCP column: informational — the daemon verifies its Lexa MCP connection (initialize+ping against /mcp) on every heartbeat and reports mcp_connected. Forge tasks do NOT require it (the daemon runs the agent CLI directly with the prompt as context); MCP is the surface for cloud agents. "Not set" is fine for Forge-only runtimes.
