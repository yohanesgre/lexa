The game crashes consistently when loading level 3-2 (The Furnace Depths). This appears to be related to the new tilemap streaming system introduced in Sprint 6.

The stack trace points to TilemapChunkLoader._loadChunk(). Suspect an off-by-one in the chunk coordinate math when transitioning between zones.

Additional investigation revealed that the issue only manifests when the tilemap exceeds 64x64 chunks. Smaller maps load without problems. We should also verify that the async loading queue doesn't have a race condition with the physics body setup.
