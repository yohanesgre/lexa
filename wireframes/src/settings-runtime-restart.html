Opens from the restart (refresh) action on an OFFLINE runtime row in Settings → Agent Runtimes. Online rows don't show it — they don't need restarting. Purpose: an offline machine keeps its runtime row. Start its machine listener; removal is not automatic. When the machine listener is online, Restart sends an update event. The listener restarts the child using its per-runtime env and the server's saved Settings configuration. While the modal is open it polls machines, runtime events, and runtimes every ~4s. When the runtime heartbeats back, the row flips to Online and the modal shows success. If installed as a systemd user service, the unit is lexa-forge-listen. No per-runtime systemd units exist.
