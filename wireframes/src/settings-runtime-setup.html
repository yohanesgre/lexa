Opens from Settings → Agent Runtimes → Setup runtime. Four-step machine-first flow: Machine → Agent CLI → Key / Send → Verify. After setup, the machine's lexa-cli listener discovers agent personas and provider/model choices and sends catalogs to Lexa. Settings owns persona, model, logging, extra args, and display name. Offline machines and runtimes are retained. Removal is an explicit action from the runtime list and is blocked while its machine is offline.
