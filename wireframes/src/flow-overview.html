Canonical paths and project context rules
Back to index

Project context rule. Board (/:slug/board), Wiki, project Settings (/:slug/settings), and the project Dashboard (status view at /:slug) are project-scoped. The Homepage (/) and global Settings (/settings) are cross-project. The global project switcher preserves the route type when possible. If the current route does not exist in the new project (e.g., a wiki page when the target project has no wiki), fall back to that project's board (/:slug/board). With zero projects, /settings still opens from the nav and renders only the global sections — Project Members and Project management are hidden (see settings-no-project.html).
