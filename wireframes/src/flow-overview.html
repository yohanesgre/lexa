Canonical paths and project context rules
Back to index

Project context rule. Dashboard is cross-project. Board, Wiki, and Settings are project-scoped. The global project switcher sets the current project and preserves the route type when possible. If the current route does not exist in the new project (e.g., a wiki page), fall back to that project's root for that route.
