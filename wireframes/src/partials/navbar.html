Forge runtimes Rows open the Forge control panel with that task's record (slideover: activity feed, result/error, timeline). The record's "Open document →" link goes to the board/wiki page. Dismiss (X) and copy stay row-local actions. Dismiss (X) hides a finished task (done/failed/cancelled) from this panel and the pill counts — per-browser, persists across sessions. On running/queued rows the X cancels the task server-side (POST /api/forge/tasks/:id/cancel), then dismisses the row. The result stays reachable in the document; only the badge is cleared. Running/queued rows show which daemon is working: project · runtime name · provider. Footer links to Settings → Forge Runtimes. The pill is ALWAYS visible — idle shows a neutral "Forge" (hammer icon, no state color); active shows amber spinner + skill; finished shows counts. It opens this panel even when idle. Each row carries its task id (mono, truncated) with a copy button — for debugging (daemon logs, API calls, MCP tools). Clicking the id copies it to the clipboard.
