The game crashes consistently when loading level 3-2 (The Furnace Depths). This appears to be related to the new tilemap streaming system introduced in Sprint 6.

Reproduction Steps

  1. Start a new game or load any save past level 3-1
  2. Enter the portal to level 3-2
  3. Crash occurs during tilemap initialization (~80% repro rate)

Investigation Checklist

  • Reproduced on Windows build
  • Reproduced on macOS build
  • Check tilemap chunk boundaries
  • Verify collision shape baking
  • Test with async loading disabled

The stack trace points to TilemapChunkLoader._loadChunk(). Suspect an off-by-one in the chunk coordinate math when transitioning between zones.

ERROR: FATAL: Null pointer dereference at: TilemapChunkLoader._loadChunk (tilemap_chunk_loader.gd:142) chunk_coords: (14, 7) buffer_size: 0
