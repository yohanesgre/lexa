Cards

Use — the card primitives for discrete content units, sized by role: .card-row for dense lists/menus/selectable rows (6px radius, 8×12 padding) · .card-panel for page-level sections — settings, dashboard, auth (12px radius, 16px padding, static) · .card-tile for navigation grids — projects (12px, 16px, hover lift + focus ring) · .chip for inline code refs (4px, 2×5).
Avoid — nesting a card inside another card (use .card-panel--elevated for the inner surface); new radii or paddings outside this scale.
Instead — flat rows with dividers for continuous lists; .github-issue-row keeps its elevated surface because it sits on a card (documented exception).

Buttons

Use — `.btn-primary` for the single primary action per view; `.btn-ghost` for secondary/inline actions; `.btn-ghost-accent` for an accent-forward secondary action tied to the brand accent ("+ New issue" in the GitHub panel); `.btn-danger-solid` for destructive confirms (delete/clear/revoke).
Avoid — multiple `.btn-primary`s in one view (dilutes the primary); `.btn-danger-solid` for non-destructive actions; `.btn-ghost-accent` as decoration on neutral actions.
Instead — `.btn-danger` (quiet outline) for destructive-but-secondary actions; `.btn-ghost` for cancel.
Variants No .btn-secondary class exists — use .btn-ghost for secondary actions. .btn-ghost-accent = ghost anatomy + --lx-text-link text; hover tints --lx-bg-accent-subtle, text stays accent.
